# RenameForge

Free portable batch file renaming tool for Windows. Find & replace, add prefix/suffix, sequential numbering, change extensions — with a live preview before anything changes. No installer, no configuration.

## Features

- **Find & Replace** — swap any text inside filenames in one pass
- **Prefix, Suffix & Extension** — add text before/after the name, or change the file extension
- **Sequential Numbering** — choose the starting number and how many digits to pad
- **Live Preview Before Renaming** — every new filename is shown side-by-side with the original first
- **Conflict-Safe** — automatically skips renames that would overwrite another file
- **Add Files or Add Folder** — pick individual files, or load a whole folder at once (with subfolders)
- **Portable** — no install, no admin rights required
- 100% free, no ads, no data collection

## System Requirements

Windows 10 or Windows 11 (64-bit). No .NET or Visual C++ Redistributable needed.

## Download
https://github.com/snagfiles/RenameForge/releases/download/rename/renameforge.zip

## Installation

1. Download the ZIP
2. Extract the files to a folder of your choice
3. Run `RenameForge.exe` — ready to use instantly, nothing else to install
